# HMCTS Claude Code Skills

A shared library of [Claude Code](https://claude.ai/claude-code) skills for HMCTS development teams. Each skill automates a repetitive part of the developer workflow — from commit messages through to release notes — running entirely from your terminal with no new tooling or CI/CD changes required.

---

## Available Skills

| Skill | Command | What it does |
|-------|---------|-------------|
| Create PR | `create-pr` | Generates a structured PR, posts GitHub PR link to JIRA, and optionally creates a Confluence release page |

More skills coming — see the [spike ticket](https://tools.hmcts.net/jira/browse/AMP) for the full planned workflow.

## Getting Started

### 1. Install Claude Code

```bash
npm install -g @anthropic-ai/claude-code
claude    # log in
```

### 2. Install the GitHub CLI

```bash
brew install gh
gh auth login
```

### 3. Set up your tokens

Add to `~/.zshrc`:

```bash
export JIRA_TOKEN=<your-jira-personal-access-token>
export CONFLUENCE_TOKEN=<your-confluence-token>   # usually the same token
```

Generate your JIRA token at: **JIRA → Profile → Personal Access Tokens**

Then reload:
```bash
source ~/.zshrc
```

### 4. Install the skills

```bash
git clone git@github.com:hmcts/claude-code-skills.git
cp -r claude-code-skills/skills/* ~/.claude/skills/
```

The skills are now available globally in every repository on your machine.

## Using a Skill

Open any repository in Claude Code and type the skill command. Example:

```
create-pr
```

Claude will read your branch, extract the JIRA ticket, draft the PR, create it via `gh`, and post the PR link to JIRA automatically.

---

## Skill Reference

### `/create-pr`

Automates the full PR and release workflow:

1. Reads git branch, commit log and diff
2. Extracts JIRA ticket from branch name (e.g. `dev/AMP433` → `AMP-433`)
3. Analyses the diff to determine what changed and why
4. Drafts a structured PR title and body
5. Checks for uncommitted changes and pushes branch if needed
6. Creates the GitHub PR and posts the PR link as a JIRA comment
7. *(Optional — say "ready to release / ship to SIT")* Creates a Confluence release page and posts the link to every ticket in the release

**Prerequisites:** `gh` CLI, `JIRA_TOKEN`, `CONFLUENCE_TOKEN`

## Contributing

To add or improve a skill:

1. Fork this repo and create a branch: `dev/AMP-NNN-skill-name`
2. Add your skill under `skills/<skill-name>/SKILL.md`
3. Raise a PR — the description will be generated by `/create-pr` itself
